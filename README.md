# おつかいAI

欲しいものを言うだけで、AIが楽天市場から探して、**AIの財布番**の承認を取ってから購入まで進める買い物代行AIです。

```
「2000円以内でコーヒー豆を買って」
  → AIが楽天で探して候補を3つ紹介
  → 「それにする」
  → 財布番に申請(300円以下は自動、それ以上はスマホで承認)
  → 承認されたら「楽天で注文する」ボタンが出る
```

📷 **写真からも頼めます。** 切れた洗剤や気になる物を撮って送ると、AIが何か特定して同じ物(なければ近い物)を探し、同じように財布番に許可を取ります。写真はブラウザで縮小してから送り、AIに一度見せたら履歴からは外します。

## 仕組み

- `src/worker.js` — Cloudflare Worker。Claude(ツール使用)+ 楽天市場商品検索API + 財布番MCP
- `public/index.html` — チャット画面(1ファイル)
- 利用者ごとの財布番の接続URLはブラウザに保存し、リクエストごとに送ります。サーバーには何も保存しません

### お金まわりの守り

- 金額はAIの言い値ではなく、**サーバーが楽天の現在価格 × 個数**で計算して財布番に申請します
- 承認されたら財布番の `payment_token` を `/redeem` で**使用済みにしてから**購入ボタンを出します。支払先・金額が承認と違えば財布番が拒否し、ボタンは出ません
- 承認待ちのあいだは画面が5秒ごとに確認し、承認されると自動で続きます
- カード番号・パスワードは扱いません。最後の注文確定は利用者が楽天の画面で行います

## 動かす

1. 楽天ウェブサービスでアプリ登録し、`applicationId`(UUID)と `accessKey`(pk_…)を取る。許可するWebサイトに公開URLを登録する
2. `.dev.vars.example` を `.dev.vars` にコピーして値を入れる
3. `npm install` → `npm run dev`(手元) / `npm run deploy`(公開)
4. 公開時は `npx wrangler secret put ANTHROPIC_API_KEY` などで秘密の値を入れ、`wrangler.jsonc` の `SITE_URL` を公開URLにする

テスト(外部APIは偽物に差し替え): `npm test`

## お金にする

- `RAKUTEN_AFFILIATE_ID` を入れると、商品リンクと購入ボタンが楽天アフィリエイトのリンクになります
- 運営側のClaude代は、`ANTHROPIC_BASE_URL` を財布番のプロキシにすれば1日の上限で止められます

## まだできないこと(次の段階)

- **注文確定の自動化**: 楽天・Amazonには外部から注文できる公開APIがありません。今は「承認済みの購入ボタン」までで、最後は利用者が押します
- **送料**: 送料別の商品は送料を含めずに申請します(画面と承認通知に「送料別」と出します)
- **Amazon・Yahoo!ショッピング**: 検索元を足せば対応できます
